# Cigario V0.5 — Integration Foundation

- Retains V0.4 luxury UIX, five-tab navigation, offline localStorage data, and full collection editing.
- Adds Account → Integration Readiness, backend handoff report and standalone offline-safe integration scripts.
- Adds versioned collection contract with UUID mapping, explicit catalog reconciliation, structured payload and immutable local change markers.
- Extends SQL with user-owned humidors, origin-lot links, transfer events, advanced review fields, allocated transfer cost, revision and import idempotency tables.
- Adds independent authenticated PHP V2 capabilities, snapshot count, import preview and initial-only commit endpoints.
- Prevents accidental demo catalog matching and fixes missing catalog fallback.
- Differentiates original purchase cost from cost allocated on partial transfers.
- Preserves existing JSON backup compatibility and saves identifier metadata with new backups.
- All network clients are dormant until users explicitly connect through a separate verified deployment workflow.
- **Not completed:** live hosting, real catalog, credentials, ongoing sync, customer onboarding/recovery, native production build and multi-user database integration tests.
